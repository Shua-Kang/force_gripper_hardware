# Force Control Gripper URDF

A two-finger parallel gripper in URDF, with PyBullet keyboard demos and a
panda-gym integration that mounts the gripper on a Franka Panda arm.

This URDF was generated by Autodesk Fusion (URDF export). The collision
geometry is a VHACD convex decomposition of the visual meshes
(`meshes/collision/*.obj`). Questions/suggestions: **xuhui@virginia.edu**

## Install

```bash
pip install -r requirements.txt
```

## The demos

- `keyboard_control.py` — both fingers move **together** symmetrically (a single open/close value), like a normal parallel gripper.
- `keyboard_control_independent.py` — each fingertip is controlled **independently** and can travel the full span (one can move all the way across to the other side); they collide with each other instead of passing through.
- `keyboard_control_franka.py` — the gripper **mounted on a Franka Panda** (`panda_with_force_gripper.urdf`); gripper open/close plus two arm joints (no task scene, just the robot).
- `keyboard_pick_and_place.py` — full **pick and place**: the mounted gripper in the panda-gym PickAndPlace scene (table, block, target). Arrow keys move the end-effector in the plane, A/Z move it up/down, Y/U, H/J, N/M rotate the tool about its three axes (K resets the rotation), O/C open/close. Grab the block and drop it on the green target.

```bash
python keyboard_control.py
```

In every demo, press **V** to cycle the display: visual + collision overlay /
visual only / collision only. The collision meshes are drawn as green ghosts
by `collision_visual.py`.

## panda-gym: gripper on the Franka arm

`panda_with_force_gripper.urdf` is the Panda arm with the stock hand replaced
by this gripper (fixed mount on `panda_link8`, TCP frame `grasp_target` at the
pinch center). It is generated with machine-specific mesh paths — regenerate
after moving the repo:

```bash
python scripts/make_panda_with_gripper.py
```

`panda_force_gripper.py` provides the panda-gym robot class and two ready
envs, drop-in compatible with the stock ones:

```python
from panda_force_gripper import PandaForceGripperReachEnv, PandaForceGripperPickAndPlaceEnv

env = PandaForceGripperPickAndPlaceEnv(render_mode="human")
obs, info = env.reset()
obs, reward, terminated, truncated, info = env.step(env.action_space.sample())
```

Finger kinematics differ from the stock Franka hand: each slider moves its
finger inward from the end of the rail, so the fingers touch when
`q_left + q_right = 0.0992` and the gripper width is `0.0992 - (q_left + q_right)`.
